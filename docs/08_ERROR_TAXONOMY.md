# Error Taxonomy

**Mục đích:** khóa các nhóm lỗi dùng cho blind error analysis.

Nhóm ban đầu: build/toolchain failure; CodeQL DB/query failure; hypothesis miss;
wrong CWE family/rank; source miss; sink miss; propagator/guard error; retrieval
omission/noise; invalid or uncompilable spec; unverified path; duplicate alert;
fixed-version persistence; calibration/routing error; label/provenance violation;
resource/budget exhaustion. Phase 13 sẽ khóa sampling và annotation guide trước
khi xem locked-test cases.
